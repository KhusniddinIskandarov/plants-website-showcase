<p align="center">
A fully responsive plants website built with Vite, TailwindCSS, and Vanilla JavaScript —<br/>
structured across 7 incremental development phases with clean modular architecture and a professional Git workflow.<br/>
Features 6 complete sections with scroll animations, Swiper carousel, WebP-optimized images,<br/>
local fonts and icons, full SEO and Open Graph support, and <strong>Lighthouse 100</strong> on Desktop Performance.<br/>
Live on Vercel, Netlify, and GitHub Pages with automated CI/CD via GitHub Actions.
</p>
