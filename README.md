</div>

---

<p align="center">

A production-ready plant website built with Vite, TailwindCSS, and Vanilla JavaScript — no frameworks, just clean modular architecture.<br/>
Structured across 7 incremental development phases: from tooling setup and layout architecture to full UI sections, interactive UX modules, and multi-platform deployment.<br/>
Every commit was made through feature branches with ESLint, Prettier, and Husky enforcing code quality at the pre-commit stage.<br/>
6 fully responsive sections with scroll reveal animations, Swiper carousel, WebP-optimized images, local fonts and icons, full SEO and Open Graph support.<br/>
Lighthouse <strong>100</strong> on Desktop Performance. Deployed on Vercel, Netlify, and GitHub Pages with automated CI/CD via GitHub Actions.

</p>
